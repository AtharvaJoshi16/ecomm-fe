# Ecommerce App - Microfrontends + Microservices

- Developed Springboot microservices as below
  - Auth
  - Gateway
    - Cart
    - Orders
    - Products
  - Service Registry

- Developed Microfrontends using React, Turborepo and Webpack5 for Module Federation.

- Utilized my custom UI library - @aj.dev/easylib-ui for UI components.
